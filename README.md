# The Vanishing Song — Campaign Dashboard

Internal, password-protected Next.js dashboard for the film's festival submissions,
social media promo calendar, and media contacts. Copy `.env.example` to `.env.local`
and fill in `SITE_PASSWORD` plus the Google Sheets service-account values to run it
against real data — without them it runs on bundled sample data out of the box.

See `SETUP.md` (to be added) for the full human-facing setup guide.

```bash
npm install
npm run dev
```
